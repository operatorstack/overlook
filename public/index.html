Agent — start here

Queue a git scan job from the browser (same as npm run cli -- scan …). The server clones the repo in the background (ingesting → chunking → analyzing → done or failed). With ANTHROPIC_API_KEY set, the host calls Anthropic once over a capped subset of units; otherwise analyze is skipped and findings stay empty. Durable sink (DB) and the versioned agent package are not done yet.

Enter the git URL (and optional ref) below, then press Start scan.
